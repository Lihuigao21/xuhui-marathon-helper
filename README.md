# 上海西岸 10K 报名辅助

这是针对 [2026 上海西岸 10K 入口](https://www.xuhui-marathon.com/b/FrAJj2/entry.html) 的本地 Windows 辅助程序。

它可以在指定时间刷新一次入口，进入正常报名链接，填写普通资料、省市区、出生日期和国家的专用选择器。普通模式仅预填；`--auto-submit` 自动核对 JSON、进入预览并提交一次，无需输入 `SUBMIT`。自动报名模式会同意本赛事已知入口协议和表单四项确认，等待官网原有倒计时；验证码/登录/排队如出现，仍须由你处理后继续。

## 安装

需要 Python 3.10或更高版本（本机验证版本为3.12），在仓库目录打开 PowerShell：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

电脑需要安装 Microsoft Edge。程序使用独立的 `.browser-profile`，不会读取现有 Edge 的 Cookie、历史或密码。

## 使用

1. 双击 `编辑资料.cmd`，填写自己的资料并保存为 `profile.json`。这个文件已被 `.gitignore` 排除，不能提交。
2. 将 `开放时间` 写成带时区的北京时间，例如 `2026-11-19T11:00:00+08:00`。
3. 抢报名时提前约两分钟运行：

```cmd
自动报名.cmd
```

4. 程序自动同意已知入口协议及表单四项确认，核对普通资料和可见预览，并点击一次最终提交；此模式无需输入 `SUBMIT`。订单或支付页面由用户继续处理。

`自动报名.cmd` 等价于 `启动助手.cmd --auto-submit`，要求填满模板中的14项普通资料。双击 `启动助手.cmd` 仅预填。旧的 `启动助手.cmd --assisted-submit` 保留手动进入预览和精确 `SUBMIT` 的确认流程，两个提交模式互斥。

只检查资料格式：

```cmd
启动助手.cmd --check-profile
```

按自动报名要求检查全部普通资料（不开网页）：

```cmd
自动报名.cmd --check-profile
```

只读检查入口和 Edge：

```cmd
启动助手.cmd --smoke
```

## 范围

普通字段包括姓名、证件、性别、出生日期、手机号、邮箱、国家、省市区、地址、血型、衣服尺码和紧急联系人。日期与国家通过实际 Mobiscroll 可见控件选择；陌生或不可用控件会提示手动。字母尺码如 `M` 会结合明确填写的性别匹配 `男M`/`女M`。请保证 JSON 资料真实正确，勿上传分享 `profile.json` 或 `.browser-profile`。

在 `profile.json` 的 `报名资料` 内加入：

```json
"所在城市": "上海市/上海市/徐汇区"
```

格式为 `省/市/区县`，例如 `浙江省/杭州市/西湖区`；直辖市也须填写两级。程序依次点击官网省、市、区县选项，并核对实际保存数据和可见文字。省、市末尾的“省/市”可在唯一匹配时省略，区县须与官网名称一致。选项不存在、控件变化或保存结果不符时，会提示“需手动”。留空或旧资料缺少这一项时跳过，不推测城市。

## 测试

```powershell
.venv\Scripts\python.exe -X utf8 -B -m unittest discover -s tests -v
```

测试只使用本地 HTML fixture 和虚构资料，不创建真实订单。

自动模式只使用正常的官网预览和提交按钮，不绕过必填项或校验。资料与 JSON 不符、确认项未完成、预览不符或按钮变化时停止或等待。点击结果未知时不自动重试，应先核对官网状态。网站开放状态、名额、验证码和报名结果取决于官网。

城市选择还在作者本机用冻结的官网原始地区数据和渲染脚本做过离线 Edge 检查，覆盖缓存地址、直辖市、普通省市和失败回读。测试材料包含第三方原始脚本，未随本仓库发布；公开回归测试使用自建本地 fixture。离线验证不等于真实开放报名、订单或付款测试。

## 自动同意的范围

运行 `自动报名.cmd`（`--auto-submit`）表示授权接受本赛事当前锁定的入口《参赛声明》及四项表单确认：18周岁以下需监护人或法定代理人签署的声明、了解装备发放信息、成绩审核、资格审核。入口声明包含参赛风险、已体检并适合长跑、充分准备及肖像等资料使用授权；请事先阅读官网条款，确认符合其中涉及的个人事实。

程序通过正常可见控件勾选和“下一步”进入报名表，保留官网5秒倒计时，不写入同意Cookie或调用隐藏提交接口。全文、选项、控件或跳转目标变化时停止自动同意；不会勾选新出现的协议。普通预填和人工 `SUBMIT` 模式仍需你处理全部声明。验证码、登录、排队及付款由你完成。

协议核对同时绑定页面初始内联参数中的完整协议配置及实际DOM（兼容已知格式的new Date日期数据字面量，解析不执行JavaScript）；验证规则、未显示选项、声明数量、签字要求或倒计时配置改变，也会停止自动同意。不能读取已知初始配置时停下；这项检查不声称能审计网页运行后私有JavaScript闭包的一切变化。

提交前会再次检查四项同意和可见预览；状态被取消或条款变化时停止。最终提交最多点击一次，点击后仍须查看官网成功/失败结果；不能把“已点击”当作报名成功。代码更新不会重试已经进行的报名。
